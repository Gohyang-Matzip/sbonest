# SBONEST API reference

Generated by `generate_api_reference.py` from the public names of the Sideband modules (functions and classes without a leading underscore, defined in the module). Regenerate after changing a public signature; CI compares this file with the generated text.

## `sideband.py`

Exact two-site NH CEST propagation using optimalcontrol (OC) operators.

- `composite_segments(p90_s=7e-05, cycle='RR', b1_scale=1.0)` — Rows (duration_s, x_Hz, y_Hz); pulse lengths stay fixed as B1 changes.
- `profile(segments, offsets, *, T, nu, kab, kba, dw, r1, r2a, r2b, ha, hb, J=92.0, r1h=2.0, r2h=25.0)` — I/I0 at RF offsets relative to site A; dw = nu_B - nu_A (Hz).
- `profile_states(segments, offsets, *, T, nu, exchange, shifts, h_shifts, r1, r2, J=92.0, r1h=2.0, r2h=25.0)` — I/I0 for an n-site NH system; sites exchange through ``exchange[i, j]`` (i -> j).
- `stationary_populations(exchange)` — Equilibrium populations of a first-order exchange network.
- `waveform_segments(path, rf_hz=None, b1_scale=1.0)` — Read OC export_json: x/y channels, uniform time grid, metadata.pulse_dt.

## `sbfit.py`

SBONEST: fit all CEST points, including decoupling sidebands, with OC.

- **class `SidebandModel`** — Reuse ONEST data, residue ordering, residuals and PDF/text reporting.
  - `__init__(self, config, config_dir='.')` — Build the model from a Sideband configuration; dataset paths resolve from config_dir.
  - `calc(self, P, i, dRF, es)` — Predicted normalized intensities of residue i at offsets dRF (ppm) for spectrum es.
  - `diagnostics(self, p, covariance)` — Result dictionary (schema 2) for a fitted vector and its full covariance.
  - `errFunc(self, p_flat)` — Residuals as in ONEST; with a worker pool the data blocks are predicted in parallel.
  - `exchange_matrix(self, P)` — Site-to-site rate matrix K[i, j] (i -> j) for the configured model.
  - `expand_name(self, name)` — Actual parameter names addressed by ``name``: itself, or all groups of an alias.
  - `fit(self, p0=None, fitting_config=None)` — Least-squares fit from p0 (or the configured grid start); returns (parameters, covariance).
  - `getLogBuffer(self, fit_output_tuple)` — Text report of a fit, including residual diagnostics and rescaled errors.
  - `init_config(self)` — The live init section with ungrouped aliases expanded to grouped names.
  - `normalize_init(self, cfg)` — Copy of an init section with ungrouped aliases expanded to grouped names.
  - `physical_bounds(self, name)` — Hard limits of one parameter: rates, RF, shifts or relaxation.
  - `prepare_fit(self, p0=None, fitting_config=None)` — Prepare current data, vectors and bounds without running an optimizer.
  - `rf_values(self, P, es)` — Actual nitrogen RF amplitude and its spread (Hz) for spectrum es under the RF mode.
  - `seParam(self, p)` — Unpack a full parameter vector into the ONEST-style dictionary plus RF and relaxation groups.
  - `selMethod(self, initConf)` — Reject init sections whose Method differs from the model this instance was built for.

## `sb_run.py`

Sideband run orchestration: preflight checks, checkpointed fits, analyses and exports.

- `build_parser(description=None)` — Argument parser shared by run.py, sbfit.py and ``sbonest check|fit|resume``.
- `check_config(config, config_dir='.', *, no_pdf=False, identifiability=False, workers=1)` — Return a JSON-safe preflight summary without optimization or file writes.
- `dispatch(parser, args, config, config_dir)` — Run ``--check`` or the fit for parsed arguments and return the exit status.
- `main(argv=None)` — Command line shared by run.py and sbfit.py for Sideband configurations; returns the exit status.
- `parse_arguments(parser, argv=None)` — Parse and cross-validate the shared command line; errors exit through the parser.
- `run_config(config, config_dir='.', no_pdf=False, *, resume=False, workers=1)` — Fit a Sideband configuration with checkpoints, optional analyses and exclusive exports; returns (parameters, covariance).

## `sb_analysis.py`

Optional multistart fits and constrained, nuisance-refitted likelihood profiles.

- **class `MultiStartError`** — All fits failed; ``attempts`` retains their starting vectors and errors.
  - `__init__(self, attempts)` — Record every attempt so callers can save failure evidence.
- **class `ProfileIntervalError`** — A profile-interval search could not be completed on one side.
- `base_fit_config(model)` — The configured fit settings without optional analyses.
- `fit_attempt(model, start, source, index, cfg)` — Fit one start and return its JSON-safe attempt row; never raises for fit failure.
- `fit_multistart(model, settings, *, completed=None, on_complete=None, pool=None)` — Fit the configured baseline plus starts; restore and return the best fit.
- `identifiability(model, p, *, pool=None, strong=0.95)` — Local linear identifiability diagnostics at p with the supplied absolute sigma.
- `local_jacobian(model, p, *, pool=None)` — Grouped finite-difference Jacobian of the Sideband residual at full vector p.
- `profile_intervals(model, p, covariance, settings, *, completed=None, on_complete=None, pool=None)` — Likelihood-ratio intervals from the exact nuisance-refit profile.
- `profile_likelihood(model, p, settings, *, completed=None, on_complete=None, pool=None)` — Nuisance-refit each requested target, preserving the original fitted state.
- `profile_point(model, p, name, target, baseline, *, pool=None)` — Constrained nuisance refit for one target; returns its JSON-safe row.
- `restore_fit(model, snapshot)` — Restore predictions, optimizer statistics and uncertainty without fitting.
- `snapshot_fit(model, p, covariance)` — Return JSON-safe fit state, including the original start and uncertainty.

## `sb_bootstrap.py`

Seeded parametric bootstrap conditional on the fitted model and absolute sigma.

- `bootstrap_draws(model, p, settings, index)` — Independent Gaussian observations for replicate ``index``, in data order.
- `bootstrap_fit(model, p, settings, *, completed=None, on_complete=None, pool=None)` — Refit independent Gaussian draws, retaining every outcome and original state.
- `bootstrap_replicate(model, p, cfg, index, observed, *, analyses=None)` — Fit one replicate's observations from the baseline; restore the model's data.
- `sample_row(model, fitted, covariance, index)` — JSON-safe summary of one refit: parameters, errors, kex/pB, chi2, bounds.
- `validate_bootstrap(settings)` — Validate init.bootstrap settings; returns normalized replicates, seed and confidence.

## `sb_checkpoint.py`

Run-owned, immutable JSON checkpoints with atomic publication and a process lock.

- **class `Checkpoint`** — Retain completed stages; an explicit resume must match execution identity.
  - `__init__(self, path, identity, *, resume=False)` — Bind a checkpoint directory to an execution identity; resume requires an identical manifest.
  - `read(self, key)` — Return a completed record (checksum verified) or None when it does not exist.
  - `save(self, key, value)` — Persist a completed record exactly once with fsync and an exclusive hard link.
- `execution_identity(metadata, *, no_pdf)` — Identity fields of a run: config, inputs, waveforms, source hashes, packages, platform, threads, PDF mode.
- `output_plan(journal, staged, destinations)` — Hash staged files and pair them with their destinations for exclusive publication.
- `publish_outputs(journal, plan, expected)` — Publish staged bytes exclusively; resume accepts only identical owned files.

## `sb_diagnostics.py`

Residual diagnostics: is the supplied sigma plausible and are the residuals structureless?

- `diagnostics_lines(report, parameter_names=None)` — Plain-text lines summarizing a residual_diagnostics report.
- `lag1_autocorrelation(values)` — Lag-1 autocorrelation of a sequence, or None when it is undefined.
- `number_text(value, digits=4)` — Format a value for text reports; None becomes 'unavailable'.
- `residual_diagnostics(rows, n_parameters, covariance=None, *, runs_alpha=0.01)` — Diagnostics from prediction rows (see ``sb_report.prediction_rows``).
- `runs_test(values)` — Two-sided Wald-Wolfowitz runs test on the signs of ``values`` (zeros dropped).

## `sb_parallel.py`

Optional process pool for Sideband work; serial by default, numerically identical.

- **class `Progress`** — Print elapsed time and a remaining-time estimate for a counted loop.
  - `__init__(self, label, total, *, enabled=True, done=0)` — Track completed items of a labelled loop starting from done.
  - `step(self)` — Count one finished item and print elapsed time and ETA when enabled.
- **class `WorkerPool`** — Process pool bound to one configuration; use as a context manager.
  - `__init__(self, workers, config, config_dir='.')` — Describe a pool of workers that each build SidebandModel(config, config_dir).
  - `evaluate_many(self, vectors)` — Full residual vectors for several full parameter vectors, one worker per vector.
  - `map(self, task, items)` — Yield results in submission order; the first failure propagates.
  - `predict_blocks(self, p, sizes)` — Predictions for every data block of the worker models at full vector p.
- `balanced_assignment(sizes, tasks)` — Assign block indices to at most ``tasks`` groups with balanced point counts.
- `bootstrap_task(payload)` — Fit one bootstrap replicate in a worker from observations drawn in the main process.
- `multistart_task(payload)` — Fit one explicit or random restart in a worker.
- `predict_task(payload)` — Model predictions for the data blocks assigned to this task.
- `profile_task(payload)` — Constrained profile refit for one target in a worker.
- `residual_task(p_full)` — Full residual vector at a full parameter vector; nonfinite values propagate.
- `study_task(payload)` — One coverage-study replicate (draws, refit, optional intervals and inner bootstrap).
- `validate_workers(value)` — Return the worker count after checking that it is a positive integer.
- `warm_task(_)` — Force a worker to finish its initializer; returns its process id.

## `sb_report.py`

Lossless Sideband reports and calculation-time provenance.

- `derived_errors(p, covariance)` — Propagate correlated exchange rates using supplied absolute-sigma covariance.
- `fit_pdf(path, rows, summary=None)` — One page per residue with profile and standardized-residual panels.
- `prediction_rows(model, p)` — Full precision observations and signed standardized residuals in input order.
- `preview_png(path, rows, *, dpi=110)` — One PNG with every residue's profile and residual panels side by side (web preview).
- `provenance(config, config_dir)` — Snapshot files before fitting, including the actual waveform bytes.
- `regenerate_report(result_path, out_prefix, predictions_path=None)` — Write a reconciled JSON/text/PDF report from saved results, without fitting.
- `reject_constant(value)` — ``json.loads(parse_constant=...)`` hook that refuses NaN and Infinity.
- `write_predictions(path, rows)` — Write prediction rows as a full-precision CSV created exclusively.

## `sb_design.py`

Experimental design: expected uncertainty of a planned Sideband measurement.

- `design_lines(summary)` — Plain-text summary of a design study, including the optimization block when present.
- `design_pdf(path, summary)` — Bar charts of expected kex/pB errors, the optimization path and the text summary as a PDF.
- `evaluate_scenario(design, scenario, folder, *, workers=1)` — Expected errors for one scenario; writes its synthetic inputs under folder.
- `load_design(path)` — Read and validate a design file; returns the base configuration, truth and scenarios.
- `optimize_design(design, out, results, *, workers=1)` — Select the measurement budget from the candidate scenario and evaluate it.
- `run_design(design_path, out, *, workers=1)` — Evaluate every scenario (and the optional optimization) into a new output directory.
- `select_measurements(jacobian, groups, budget, gradient, *, min_per_dataset=2)` — Backward elimination of spectrum rows that least worsen the criterion.

## `sb_compare.py`

Compare a shared-exchange (global) Sideband fit with per-residue individual fits.

- `compare_models(config, config_dir, out, *, models=('Sideband', 'Sideband_3st_Linear'), h_ppm_c=None, no_pdf=True, workers=1)` — Fit the same data with several Sideband models and compare AICc/BIC.
- `comparison_lines(summary)` — Plain-text lines of a shared-versus-individual comparison.
- `comparison_pdf(path, summary)` — Per-residue kex/pB with errors against the shared fit, plus the text summary, as a PDF.
- `information_criteria(chi2, k, n)` — Gaussian AICc/BIC up to the common constant, with the supplied absolute sigma.
- `models_lines(summary)` — (no docstring)
- `nested_f_test(chi2_small, k_small, chi2_large, k_large, n)` — F-test of the smaller (shared) model against the larger (individual) model.
- `run_comparison(config, config_dir, out, *, no_pdf=True, workers=1)` — Fit the global and the individual models; write comparison JSON/TXT/PDF.
- `summarize(global_fit, individual, labels)` — Combine the global and individual fit records into the comparison summary.
- `three_state_config(config, method, *, h_ppm_c=None, starts=None, labels=None)` — Derive a three-state configuration from a fitted two-state configuration.

## `sb_workflow.py`

Sideband workflow helpers: demo setup, saved-result reports, design and model comparison.

- `init_demo(out)` — Copy bundled synthetic two-RF inputs into a new, exclusively owned folder.
- `main(argv=None)` — Command line: init-demo, report, design and compare; returns the exit status.

## `sb_import.py`

Convert Bruker processed pseudo-2D CEST data into SBONEST text input.

- `convert(pdata, offsets_path, out, *, peaks, half_width, reference_row, noise_region, saturation_s, v1_hz, v1err_hz=0.0, offset_unit='ppm', carrier_ppm=None, nucleus='15N', field_mhz=None, mode='max', dw_ppm=None, r2a=10.0, r2b=20.0, exclude_rows=(), qa_path=None)` — Write one SBONEST dataset; return a summary dict.
- `find_peaks(row, ppm, *, threshold, min_separation_ppm=0.03, limit=50)` — Local maxima of one spectrum row above ``threshold``, as (ppm, height) sorted by height.
- `main(argv=None)` — Command line of the Bruker pseudo-2D converter.
- `noise_sigma(row, ppm, region)` — Standard deviation of one spectrum row inside a signal-free ppm region.
- `peak_intensities(data, ppm, peaks, half_width, *, mode='max')` — Intensity of every peak in every row within +/- half_width ppm.
- `peaks_from_reference(pdata, reference_row, noise_region, *, snr=10.0, min_separation_ppm=0.03, limit=50)` — Candidate proton peaks (label, ppm, height) from the reference row of a pseudo-2D.
- `qa_pdf(path, data, axis, peaks, half_width, reference_row, noise_region, offsets, keep, heights, sigma)` — QA figure: reference row with windows and noise region, then each extracted profile.
- `read_offsets(path, *, unit, carrier_ppm=None, field_mhz=None)` — One saturation offset per row from a text list; Hz values need a carrier.
- `read_parameters(path)` — Parse a Bruker JCAMP-DX parameter file into a dict of scalars and lists.
- `read_pseudo2d(pdata)` — Return (rows x points) real data and axis information from a pdata directory.

## `sb_server.py`

Sideband web interface: upload, preflight, background fitting, reports and previews.

- `analysis_settings(form)` — Translate the analysis form fields into init keys; invalid values raise ValueError.
- `archive_expired(max_age_days)` — Move jobs older than max_age_days into the archive directory; return their ids.
- `archive_expired_jobs()` — Archive every idle job older than the configured maximum age.
- `archive_job(job_id)` — Move a finished job into SB_JOBS/archive/ (nothing is deleted).
- `create_job()` — Store the upload, rewrite the configuration and run the preflight check.
- `download(job_id, filename)` — Serve one file from inside a job directory.
- `index()` — Single-page runner interface.
- `job_status(job_id)` — Process state, checkpoint records, result summary and log tail of a job.
- `list_jobs()` — Names, ages and states of all job directories.
- `main(argv=None)` — Start the Flask runner.
- `make_report(job_id)` — Regenerate the saved-result report with a fresh prefix.
- `preview(job_id)` — PNG preview of the fitted profiles, rendered from the predictions CSV and cached.
- `resume_fit(job_id)` — Resume an interrupted or finished job through its checkpoint.
- `start_fit(job_id)` — Start the fit as a background run.py process.

## `sb_cli.py`

Unified SBONEST command line: ``sbonest <command> ...``.

- `build_parser()` — Argument parser of the sbonest command (delegated commands keep their module's help).
- `main(argv=None)` — Entry point of the sbonest command; returns the exit status.

## `validate_uncertainty.py`

Seeded synthetic coverage of Sideband uncertainty intervals.

- `coverage_summary(samples, parameter_names, varying_parameters, truth, confidence=0.95)` — Count local normal intervals using positive finite SEs only.
- `main()` — Command line of the synthetic coverage study.
- `run_study(config_path, truth_path, replicates, seed, out, confidence=0.95, *, profile_interval=None, inner_bootstrap=None, workers=1)` — Validate truth, preserve inputs, and refit one fresh dataset per replicate.
- `study_replicate(model, p, cfg, settings, index, *, interval_settings=None, inner_settings=None, pool=None)` — One study replicate: fresh draws, refit from truth, optional intervals and inner bootstrap.
